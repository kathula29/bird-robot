# \# Original Owl-Inspired Walking Robot

# 

# This project is for the development of an original owl-inspired

# indoor walking robot.

# 

# The confirmed visual direction is an owl face with a closed-beak

# appearance. Reference images guide the appearance only; they are

# not final engineering drawings.

# 

# Microduck is a technical reference only. It is not our product design.

# Any external code or design assets must have their source, licence

# and reuse decision recorded before inclusion.

# 

# \## Planned capabilities

# 

# \- Supported standing on a flat indoor surface.

# \- Slow, controlled steps after calibration and walking setup.

# \- Head movement, including assessment of the 360-degree rotation goal.

# \- Safe integration of motors, controller, power source and sensors.

# 

# Component fit, weight, balance, movement clearance and head wiring

# remain subject to design and testing.

# 

# \## Repository folders

# 

# | Folder | Purpose |

# | --- | --- |

# | CAD/editable | Editable CAD source files |

# | CAD/STL | Mesh exports for printing |

# | CAD/STEP | STEP files for CAD exchange |

# | CAD/drawings | Drawings and design reference images |

# | firmware | OpenRB-150 controller firmware |

# | host-software | Software running on the development computer or onboard computer |

# | simulation | Robot models and simulation configurations |

# | tests | Test scripts, procedures and recorded results |

# | BOM | Bill of materials and component-list references |

# | logs | Daily build logs |

# | docs | Project documentation, revision records and setup instructions |

# 

# Folders may contain placeholders where work has not started.

# 

# \## Version records

# 

# Hardware models/revisions, software versions and CAD revisions are

# recorded in docs/revisions.md.

# 

# Git commits identify the exact repository version. Test records should

# refer to the commit and relevant hardware/software/CAD versions used.

# Unknown versions must be marked pending rather than assumed.
